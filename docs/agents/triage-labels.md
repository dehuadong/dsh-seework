# Triage 标签

Skills 使用五个标准 triage 角色。本文件将角色映射到本工程 issue tracker 中实际使用的标签名。

| Skill 内部角色     | 本工程标签       | 含义                     |
| ------------------ | ---------------- | ------------------------ |
| `needs-triage`     | `needs-triage`   | 需维护者评估             |
| `needs-info`       | `needs-info`     | 等待提问者补充更多信息   |
| `ready-for-agent`  | `ready-for-agent`| 规格完备，agent 可领取   |
| `ready-for-human`  | `ready-for-human`| 需人工实现               |
| `wontfix`          | `wontfix`        | 不予处理                 |

当 skill 提及某个角色（如「打上 AFK-ready triage 标签」），使用上表中对应的标签名。

标签名沿用 SeeAI Hub 仓库的同名字符串，便于两边的工作互相搬移。如需调整命名，修改右列即可；本文件登记标签**字符串**，不表示已经或允许在远端创建标签。
