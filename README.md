# dsh-seework — 在对话里用 SeeAI Hub 生图

DeepSeek Harness（DSH）Web GUI 的插件工程。装上它以后，你可以在对话里直接让 Agent 生图，图片以卡片形式显示在对应工具调用的那一行；所有生成过的图片会同时落进本机素材目录，会话右上角的「素材库」用来回看历史，「画布」用来把它们摆到一块自由空间板上（两个面都开在 DSH 的右侧栏；没有会话的首页用右下角浮动按钮）。

只用自己的 SeeAI Hub 用户 API Key 说话：设置里填一次地址和 Key，插件负责把请求转发到 SeeAI Hub 的图片接口，密钥只留在本机。



## 第 1 阶段：对话窗口生图

已经交付的能力：

| 能力 | 说明 |
| --- | --- |
| 设置页 | 「设置 → 插件 → SeeWork」；找不到入口时用右下角浮动的「SeeWork 设置」按钮。填 **两个地址**（生成网关 / 模型目录）与用户 API Key，点「检测可用模型」后勾选保存。 |
| 模型目录 | SeeAI Hub 的目录是 **service**（默认 `127.0.0.1:8081`）的 `GET /api/v1/catalog/models`，不在生成网关上。插件先问 service 地址，再试网关同路径，最后退到 OpenAI 兼容的 `/models`；每次都把「问了哪个地址、各自回了什么」显示出来，所以检测不出模型时你能直接看到原因。 |
| 参数按模型裁剪 | 插件只提供**五个常规参数**（`model` / `n` / `resolution` / `aspect_ratio` / `output_format`），以及同一个工具上**可选的 `reference_images`**（不传＝文生图，传了＝改图）。目录声明了哪些档位、比例、输出格式与参考图张数，请求前就按这张表裁剪——表里没有的值不发（发过去就是 400）。**模型特有的额外字段（画质、水印、种子、`background`、`size` …）插件一律不发**：工具 schema 里没有它们，也没有别的通道。只有「只拿到模型名」的裸网关才原样透传，因为那时我们确实不知道。 |
| Agent 工具 | `generate_image`：不传 `reference_images` 就是文生图，带上它（会话里已有的图）就是改图。图片生成是同步的：一次调用就拿到结果，没有任务号可查、也没有可取消的任务。图会出现在**两个地方**：助手回复的正文里和工具调用那一行的图片卡片。正文里的图按缩略图显示（最长边 320px），**点一下在原位放大看原图**（Esc 或点背景关闭，Ctrl / 中键仍是新标签页打开）；卡片则是标题 + 状态 + 缩略图。模型看到的是纯文本 JSON（所以纯文本对话模型也能用），结果里每张图还带素材库文件名 / 可访问地址 / 完整 http 地址 / 本机绝对路径。 |
| 请求映射 | 严格按 SeeAI Hub 的字段词汇发请求（`resolution` / `aspect_ratio` / `output_format` / `image_urls`），绝不发明字段。 |
| 本地素材 | 每张生成图写进数据目录并在 `index.json` 里建一条记录（提示词、模型、参数、费用、来源），供第 2 阶段素材库和第 3 阶段画布读取。 |

### 它怎么工作

```
对话 / Agent
   │  generate_image 工具
   ▼
宿主进程（插件宿主半边）                    浏览器（插件客户端半边）
   ├─ 设置区（settings 命名空间 dsh-seework）   ├─ 设置卡片（设置对话框左侧导航 settings.section，
   ├─ /api/dsh-seework/* 路由                   │   拿不到导航槽位时退化为插件 tab / 浮动面板）
   │   ├─ settings/describe|mutate 设置桥       ├─ 素材库 / 画布（右侧栏 tab；右上角入口切换）
   │   ├─ catalog/models  模型目录              ├─ 会话里的图片卡片（tool.call.toolview 键控槽）
   │   ├─ generate        生图代理              └─ 通过同源 fetch 调上面的路由
   │   ├─ tasks/list|cancel
   │   ├─ library/*       素材库
   │   ├─ attachment/image 工具结果里的图片
   │   └─ canvas/*        画布
   ├─ 生成队列（同一模型串行，不同模型可并行）
   └─ 数据目录 ~/.dsh/dsh-seework/（素材库 + 画布）
```

密钥只存在于宿主进程读取的设置文档里；浏览器拿不到，生图请求由宿主转发，所以没有 CORS 问题。

### 两个地址为什么分开

SeeAI Hub 的对外文档把两类服务分得很清楚：**Gateway**（`/v1/*`，模型生成）与 **service**（`/api/v1/*`，登录、账户、模型目录、账务），而且「路径互不代答」——目录端点在 service 上，网关不会代答它。所以插件有两个地址设置：

| 设置 | 默认 | 用途 |
| --- | --- | --- |
| API 地址 | `http://127.0.0.1:8080/v1` | 生图请求（Agent 工具与后续画布） |
| 模型目录地址 | `http://127.0.0.1:8081` | 只在「检测可用模型」时用 |

如果你的部署把两者挂在同一个域名下（反向代理），两个都填那个域名即可——插件两个地址都会试，并在结果里告诉你哪个答的。

## 第 2 阶段：素材库

会话右上角的「素材库」入口在 DSH 右侧栏打开素材库，里面是**你用 SeeWork 生成过的全部图片**——对话里让 Agent 画的、以后面板上画的，都在这里。（没有会话的首页用右下角浮动按钮。）

- **按天分组**：今天 / 昨天 / 具体日期，每组显示当天生成了几次。
- **搜索与筛选**：搜提示词（不区分大小写），按模型、按来源（对话 / 面板 / 画布）筛；点某天的标题就只看那天，再点一下取消。
- **详情大图**：点缩略图或提示词打开大图，多张时用底部左右翻页（也可以按 ← / →），Esc 关闭。详情里「提示词」标题右边有个显眼的**「复制提示词」按钮**（以前它挤在提示词文字下面，看着不像按钮）；标题下方有**「加到画布」**（放当前翻到的那张）与**「加入到对话框」**（把这张图塞回输入框当草稿附件）。
- **完整信息**：提示词（一键复制）、模型、档位、比例、尺寸（当前这张的像素宽高）、格式、张数、扣费、参考图名、每张图的文件名与像素尺寸。老条目记录里的画质留在数据里不动，但界面不再展示（画质已不是插件参数）。
- **删除**：详情里可以删单条（会弹一次确认），删掉的图片文件同时从磁盘移除；删除后立即从列表消失。
- **读取失败不清空**：素材库暂时读不到时，列表保留上次读到的内容并提示原因，不会白屏。

素材库读的就是第 1 阶段已经在写的本地索引，所以它不需要额外记录任何东西——生成链路一行没改。

## 第 3 阶段：画布

会话右上角的「画布」入口在 DSH 右侧栏打开一块**自由空间板**——不是节点图，没有端口也没有连线：卡片就是摆在那儿的矩形，你自己安排位置和大小。这是 SeeAI TV 画布的形态，也是你指定的方向。生图之后画布**不会**自动打开、也不会有图自动上板（免得后台一次生成就把你的屏幕重排）；要上板有四种办法：**对话里点开大图后按「加到画布」**、**工具调用那张卡片里每张图下面的「加到画布」**、**素材库卡片上的「加到画布」**（详情浮层里也有一个，放当前翻到的那张），或者画布里的「从素材库选图」。前几种点完都会把画布打开给你看结果，图片落在当前视野中央。

- **多块画布**：左侧列表新建、切换、重命名、删除（删的是这块板，不动素材库）。
- **点图浮出指令条**：在画布上点中一张图片，图旁边会浮出一条指令条（上方放不下会自动翻到下方），上面有三个入口：
  - 「**加入到对话框**」——把这张图塞回对话输入框当草稿附件，直接接着改图或追问，不用重新上传；
  - 「**标注**」——打开标注编辑器（一个居中的面板，不会随画布栏拉宽而铺满整屏）：**画笔涂抹、矩形框选、箭头指向、文字说明、橡皮擦**五种可以混用，还能选颜色/粗细、撤销重做（Ctrl+Z / Ctrl+Shift+Z）。文字是**点一下图（松手）就出现输入框，可以直接打字**：回车确认、Esc 取消这次输入（不会把编辑器一起关掉）、点框外也确认；橡皮擦是**按对象擦除**（拖过哪个标注就删哪个，可撤销）。保存后烧录成**一张合成图**，作为**新卡片**放回画布（原图与素材库都不动）；
  - 「**裁剪**」——就地裁剪：图上出现裁剪框（三分格线、八个手柄、可整体拖动），旁边的工具栏能选比例（自定义 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16）、看当前尺寸，确认后生成**新卡片**（原图保留）。
  标注与裁剪的产物存在画布自己的目录（`<数据根>/canvas/assets/`），**不进素材库**——素材库记的是"生成过什么"，涂改过的一张不是一次生成。每张图卡片的标题栏都有**来源徽标**（对话生成 / 面板生成 / 标注合成 / 裁剪合成），一眼看得出它是哪儿来的；**移除合成图卡片时它的文件会一起删掉**（素材库图片则原样保留，提示里会写明），攒下的历史孤儿图片用工具栏的「清理无用图片」一次清掉（只删板上没有任何卡片引用的那些）。卡片太多、有图被压在最底下点不到时，用工具栏的「图层」：按从下到上的顺序列出所有卡片，点一行就选中它并提到最上层（不在视野里还会自动挪到视野中央）；**点一下画布它就收起来**，不占地方。清理之类的回报提示几秒后自己消失。
- **摆放**：拖卡片标题栏移动、右下角调整大小；位置和尺寸按板坐标存（当前缩放下拖动不会漂）。**点中哪张卡片，它就升到最上层**——刚放上来的图永远在最上面，所以点一下就能把它拽出来，不会被后放的图压住。
- **缩放**：滚轮以**光标为锚点**缩放（光标下那一点不动）、工具栏 ± 与「100%」、以及「适应内容」把全部卡片摆进视野；网格点距随缩放自适应，不会糊成一片或稀到看不见。
- **内容**：从素材库挑图放到板上（保持原图比例，落在当前视野中央），或「加备注」写一张文字卡（可直接在卡片里编辑）。
- **删除**：卡片右上角 ✕ 只是从板上移除，**不删素材库里的图**。
- **自动保存**：改动 0.8 秒后自动存盘，工具栏右侧显示「已保存 / 待保存 / 保存中 / 保存失败」。
- **多窗口**：同一块板在别处被改过时，宿主会拒绝这次写入（修订栅栏）。插件随即重新读取最新版本号并**把你的版本重试保存**——你的布局不会被别人的版本悄悄替换掉。

数据存在 `<数据根>/canvas/<id>.json`，一块板一份文件。

## 安装

```bash
# 在 dsh 的 web profile 目录里把本工程作为本地依赖加入
dsh plugin --profile web add file:E:/workspace/dsh-plugin/dsh-seework
# 重启 dsh web 生效
```

`lib/` 下是构建产物并随仓库提交：DSH 宿主装载插件时读的是构建好的 bundle，不会替你构建，所以克隆下来就能直接用。

> **注意 `file:` 装的是副本，不是链接**。`dsh plugin ... add file:` 会在 profile 的 `node_modules` 里放一份**拷贝**，所以本地改完 `pnpm build` 之后必须再同步一次，否则 GUI 一直加载旧 bundle，而且**不会报任何错**：
>
> ```bash
> pnpm build && pnpm sync          # 同步到默认的 web profile
> node scripts/sync-to-profile.mjs --profile add    # 其他 profile
> node scripts/sync-to-profile.mjs --dry-run        # 只看要不要同步
> ```
>
> 同步完重启 `dsh web` 生效。

首次使用：

1. 打开「设置 → 插件 → SeeWork」（或点右下角「SeeWork 设置」；多数版本里它在设置对话框左侧导航的 `SeeWork` 一页）。
2. API 地址默认 `http://127.0.0.1:8080/v1`；填你在 SeeAI Hub 后台创建的设备 Key。
3. 点「检测可用模型」，勾选要用的模型，保存。
4. 回到对话，让 Agent 画一张图。

> 卡片底部的「本地与行为」里，**素材目录点「选择目录…」挑**：会弹出系统的文件夹选择窗口（Windows 是资源管理器那个），选完立刻生效，旧目录里的文件不会被删；想回到默认点「恢复默认」。宿主开不出系统窗口时（远程 / SSH 场景）按钮不出现，卡片会说明原因。**水印默认关闭，插件设置里也没有这一项**：加水印与随机种子都是豆包（Seedream）系模型自己的请求参数，不填就用网关默认（不加水印、种子随机）。**但本插件不负责发它们**——插件只发那五个常规参数，画质与模型特有的额外字段都没有通道。

## 开发

```bash
pnpm install
pnpm typecheck     # tsc --noEmit
pnpm test          # vitest run（宿主 + 客户端）
pnpm build         # tsdown：lib/index.js（宿主）+ lib/client.js（浏览器）
node scripts/smoke.mjs   # 对着构建产物跑端到端（自带桩网关）
```

`scripts/smoke.mjs` 是最省事的回归入口：它起一个桩 SeeAI Hub 网关，把真实路由挂到真实 HTTP 上，跑通「检测模型 → 文生图 → 落素材库 → 图生图 → 各类拒绝（含 409 只报一次、不重试）」，不需要 GUI。

## 安全与额度

- **密钥**：只存在本机 DSH 设置文档（`~/.dsh/settings.yaml` 的 `dsh-seework` 段），界面只显示「已保存」；设置桥读到的是脱敏值，写入走路径操作，不会把密钥回传浏览器。
- **额度**：每次都真实扣 SeeAI Hub 账户额度。成功响应里的 `cost` 会被记进素材库记录。
- **并发**：SeeAI Hub 对同一用户同一模型同时只允许一个生图请求，而且那把锁要到该请求结束才释放。插件自己也按模型串行排队，所以本进程不会撞上；万一同一个 Key 在别处占着这把锁（另一个会话、别的客户端），插件只如实报错并提示**请勿重试**——几秒后再试会撞上那个还在跑的请求。
- **内容**：图片由上游模型生成，可能不符合预期，使用前请自行检查。
- **图生图**：参考图会以 data URL 发给你配置的 SeeAI Hub 网关，敏感图片不要上传。
